Some of the highlights of this release are:

- iOS: Modes UI and transport-specific map styles by @yannikbloscheck and @eisa01
- Android: Display Mangrove user reviews in POI info page by @mmakowski
- Custom map font size setting by @hackintosh5
- Support roadshields in Kyrgyzstan, Uzbekistan, Tajikistan, Kazakhstan by @soshial
- Display favourite names on the map by @vng, @biodranik, @kirylkavern via OM and @LMBishop
- Android: Allow TalkBack users to read the map by @hackintosh5
- Android: Ability to start track recording after navigation start by @kvanrooyen

...and many other improvements, see [the full list on Codeberg](https://codeberg.org/comaps/comaps/releases/tag/v2026.08.31-14)!
